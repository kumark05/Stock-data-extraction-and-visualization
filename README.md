# Stock data extraction and visualization
## Overview
This project explores historical stock prices and revenue data for 2 companies: Tesla and GameStop. It demonstrates data extraction, web scraping, data cleaning, and data visualization.  
## Technologies used
- **Python**: programming language
- **yfinance**: Historical stock price data extraction
- **Requests**: retrieving web page content
- **BeautifulSoup**: Web scraping revenue data from web pages
- **Pandas**: Data manipulation and cleaning
- **Matplotlib**: Data visualization

## Project Workflow
1. Extracted historical stock price data for Tesla and GameStop using **yfinance**.
2. Retrieved revenue information from web pages using **BeautifulSoup** and **Requests**.
3. Cleaned and processed the data using **Pandas**, including formatting revenue values and handling missing data.
4. 5. Created a reusable visualization function using Matplotlib to plot date vs. stock closing price and date vs. revenue for Tesla and GameStop.
5. Created visualizations comparing stock prices and revenue over time
